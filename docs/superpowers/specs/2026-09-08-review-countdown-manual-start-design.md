# Review Countdown Manual Start Design

## Goal

复习模块启用倒计时时，每次进入一个复习模块后都不立即计时。用户必须首次手动点击“继续倒计时”按钮或按空格，当前词才开始倒计时；本次模块会话中的后续单词随后自动开始倒计时。

## Scope

- 适用于所有实际启用倒计时的复习模式：英文读、中文读、中文写。
- 英文拼继续沿用现有规则，不启用也不显示倒计时。
- “首次”以每次进入复习模块为边界。离开后重新进入、切换复习模块、切换孩子或重新加载该复习队列时，都重新要求手动启动。
- 首次手动启动前，即使用户直接评分或前后切换单词，倒计时仍保持暂停；只有明确点击“继续倒计时”或按空格才解锁后续自动倒计时。

## Relevant Code

- `src/components/ReviewSession.tsx` 管理复习队列、当前词、倒计时状态、按钮和空格快捷键。
- `src/components/Workspace.tsx` 根据当前复习模式挂载 `ReviewSession`，并通过 `key={reviewMode}` 在切换模式时创建新的组件会话。
- `src/lib/reviewCountdown.ts` 保存倒计时时长规则，包含三个及以上英文单词的词组时长翻倍逻辑。
- `src/components/reviewKeyboard.ts` 判断空格键是否可切换倒计时暂停状态。
- `tests/reviewCountdown.test.ts` 和 `tests/reviewKeyboard.test.ts` 覆盖倒计时及快捷键的纯逻辑。

## Chosen Approach

在 `ReviewSession` 内增加本次模块会话的“倒计时已手动启动”状态，不把该状态提升到 `Workspace`，也不写入浏览器或用户配置。

这个范围与需求一致：

- 组件挂载时状态为未启动；
- `Workspace` 切换复习模式时现有 `key={reviewMode}` 会重建组件并自然重置；
- 切换孩子、语言或复习类型导致队列重新加载时也显式重置；
- 不会在页面刷新、离开模块或下一次进入时错误保留启动状态。

## State Flow

1. 队列加载完成并显示首个词时，若倒计时已配置为启用：
   - 设置完整剩余时长；
   - 保持暂停；
   - 按钮显示“继续倒计时”。
2. 用户首次点击按钮或按空格：
   - 将本次模块会话标记为已启动；
   - 当前词立即从完整剩余时长开始倒计时。
3. 会话已启动后，用户评分、前后切词或进入补做词：
   - 新词重置为该词的完整时长；
   - 自动开始倒计时。
4. 会话尚未启动时，用户评分或前后切词：
   - 新词重置为完整时长；
   - 仍保持暂停，等待首次手动启动。
5. 用户在会话已启动后点击暂停：
   - 只暂停当前词；
   - 再次点击继续后恢复；
   - 后续新词仍自动开始。
6. 倒计时归零时继续沿用现有行为：自动判为“彻底陌生”，但停留在当前词。

## Implementation Boundaries

- 将“新词展示时是否应暂停”的判断抽到 `src/lib/reviewCountdown.ts` 中作为纯函数，避免在多个 effect 和事件处理函数中复制条件。
- `ReviewSession` 保留现有剩余毫秒和定时器实现，只增加会话启动状态，并调整队列加载、切词重置和首次继续操作。
- 按钮标题、无障碍标签和空格快捷键继续由 `isPaused` 驱动；首次未启动状态对用户表现为普通的“继续倒计时”。
- 词组倒计时翻倍、评分逻辑、队列补做顺序和倒计时关闭配置不改变。

## Error Handling

倒计时是纯前端状态，不新增网络调用。现有 effect 清理 interval 的机制保留，切词、暂停、卸载和配置变化时都应停止旧定时器，避免多个 interval 同时运行。倒计时关闭时，手动启动状态不应创建定时器或显示控制按钮。

## Testing

扩展倒计时纯逻辑测试，覆盖：

- 启用倒计时时，未手动启动的首词保持暂停；
- 未手动启动前切换到其他词仍保持暂停；
- 首次手动启动后，新词自动开始；
- 会话已启动后的人工暂停不撤销后续自动启动能力；
- 倒计时关闭时不启动计时；
- 原有单词、双词和三个及以上词组的时长规则保持不变。

同时运行现有键盘测试，确认空格仍能切换暂停/继续，并运行生产构建验证类型和组件集成。
